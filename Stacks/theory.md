Introduction to Stacks
Theory (Easy Words)

A Stack is a linear data structure that follows LIFO — Last In, First Out.

Think of a stack of plates — you can only add a plate on top, and you can only remove the plate that's on top. You can't pull a plate from the middle without removing the ones above it first.

Core Operations:

push(x) — add element x on top
pop() — remove the top element
top() / peek() — see the top element without removing it
isEmpty() — check if stack has no elements
size() — count of elements

All operations are O(1) — that's the whole point of a stack, fast access to just the top.
